Event Management Process

Artisans can submit requests for Workshops, Exhibitions, or Competitions. The administration reviews the requests and can open a live discussion when an event type receives sufficient interest. Event details such as date, time, location, and participation requirements are decided during the discussion before the final event is published.

1. Requests

Artisans submit requests for the event type they would like Craftora to organize.

2. Review Interest

Admin reviews the number of requests and identifies events with sufficient interest.

3. Live Discussion

Admin opens a discussion where artisans can discuss the event and its requirements.

4. Publish Event

Final details are decided and the completed event is published for registration.
